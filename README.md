CodeAlpha Data Visualization Project

📊 Project Overview

This project focuses on visualizing Superstore sales data using Python. It explores sales patterns across product categories, regions, customer segments, products, and time.

🎯 Objective

To analyze sales data using charts and graphs, identify trends, and present useful business insights.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

📁 Dataset

Superstore Sales Dataset in Excel format.

📈 Visualizations Created

1. Total Sales by Category
2. Total Sales by Region
3. Sales Distribution by Segment
4. Top 10 Products by Sales
5. Monthly Sales Trend

🔍 Analysis

The project compares sales across different categories, regions, and customer segments. It also identifies high-selling products and visualizes how sales change over time.

📝 Conclusion

Data visualization makes it easier to understand sales performance and identify patterns in the dataset. The charts created in this project can help support data-driven business decisions.

▶️ How to Run

1. Open the Jupyter notebook in Google Colab.
2. Upload the required Superstore Excel dataset.
3. Run the notebook cells.
4. Review the generated charts and findings.
